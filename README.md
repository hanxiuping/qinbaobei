# 亲宝贝家庭云相册

一个参考亲宝宝 App 使用体验的家庭媒体网站，用于添加宝宝照片和视频，并按时间线展示成长记录。

## 功能

- 通过微信小程序客服消息的一次性链接安全登录
- 按小程序 OpenID 对应权限控制访问
- 添加照片和视频到上传队列
- 打开百度网盘手动上传入口
- 标记文件已手动上传
- 按时间线浏览照片和视频缩略图
- 点击缩略图查看大图或播放视频
- 支持全部、照片、视频筛选

当前版本不会静默上传文件到百度网盘。自动上传需要接入百度开放平台 OAuth 和网盘上传 API。

## 运行

```bash
npm ci
npm run dev
```

